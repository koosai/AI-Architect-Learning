# 从零到 AI Architect

这套教材的目标不是让你背“高并发八股”，也不是把 AI 当成一个会回复文本的 API。它要训练的是架构师的基本动作：理解需求、建模系统、识别约束、设计边界、验证方案、解释取舍。

你现在可以把自己当成一个刚进入工程世界的学习者。第一阶段会慢一些，因为系统设计并不是孤立知识；它依赖编程、网络、数据、测试、部署、观测和安全。后面的 AI Architect 路线也一样，RAG、Agent、多智能体都必须建立在这些底座上。

## 本教材如何使用

每一章都按同一套结构组织：

1. 学习目标：说明学完以后你应该能做什么。
2. 零基础解释：先用普通语言建立直觉。
3. 关键术语：保留英文术语，避免未来读资料断层。
4. 图解与代码：用 Mermaid、React 交互组件和 Python/TypeScript 示例连接概念。
5. 常见误解：专门指出初学者容易走偏的地方。
6. 练习与复盘：要求你画图、写代码、录音讲解或做小型评审。

## 评价标准

你每个月至少要留下三种证据：

- 一张架构图：能让别人看懂组件和数据流。
- 一段可运行代码：能证明你理解了关键行为。
- 一段解释稿：能说明需求、约束、取舍和风险。
