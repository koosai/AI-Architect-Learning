Month 2 你学会了"读多写少该上缓存、写爆了要分片"。但缓存为什么会击穿？索引为什么有时反而更慢？队列怎么保证不丢消息？这个月带你打开数据系统的引擎舱，看清里面的齿轮。

## 为什么数据层值得一整月

绝大多数线上事故和性能瓶颈，最后都落在数据层：慢查询、缓存不一致、消息丢失、热点 key、事务死锁。**能驾驭数据层，是初级和资深工程师最明显的分水岭。** 这个月就专攻它。
