# 架构案例库（Architecture Atlas）

课程的月度章节教你**概念和方法**；这个案例库带你看这些方法在**真实世界**里怎么落地。每一个案例都不是"它很厉害"的赞美，而是回答四个硬问题：

> 它当初想解决什么问题？它的架构长什么样？它用了哪些设计模式/思维？它是怎么一步步演进成今天这样的？

## 每个案例固定 7 块

1. **规模数字**：用户量、QPS、数据量——先建立尺度感。
2. **设计初衷**：诞生时面对什么问题、什么约束。
3. **架构总览图**：一张 Mermaid 图看清主要组件和数据流。
4. **关键设计模式 / 设计思维**：回扣课程里的概念（边界、状态、失败模式、并发……）。
5. **架构升级史**：交互时间轴——每个时代改了什么、**为什么**改。
6. **权衡与教训**：它放弃了什么来换取什么。
7. **来源**：工程博客、论文、官方资料，全部真实可查。

:::info 关于可靠性
案例库的所有事实都来自公开的工程博客、技术演讲、论文和官方文档，并在每页末尾列出来源。架构会随时间变化，本库记录的是"截至撰写时已公开的设计"，并尽量标注年份。
:::

## 怎么用这个案例库

- **配合月度章节看**：学到某个概念时，来这里找一个真实例子印证（每个案例都标了"对应课程概念"）。
- **当作面试弹药**：系统设计面试常考这些系统，理解它们的"为什么"比背组件名有用得多。
- **学演进思维**：重点读每个案例的"架构升级史"——真实系统都是被问题逼着一步步长出来的，没有一开始就完美的设计。
