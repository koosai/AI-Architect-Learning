## 为什么是一个月，而不是一节课

很多教程把"基础"一句话带过。但真正让初学者卡住的，恰恰是这些"基础"里藏着的工程判断：

- 输入要校验到什么程度？错误怎么分类？
- 状态放内存还是数据库？两个请求同时来会怎样？
- 一次请求到底经过了哪些环节？哪一环最容易慢、最容易挂？
- 怎么证明你的代码是对的？怎么知道线上正在发生什么？

这些问题每一个都值得一节课。学完这一个月，你不再是"会写函数的人"，而是"能把函数组织成可靠系统的人"。

## 月末 Capstone 预览

L16 会要求你把前面 15 节课学到的东西**合并成一个东西**：一个报名服务，具备 API 边界、输入校验、错误码、持久化、幂等、并发安全、单元+集成测试、结构化日志，并能说出它的 p95 延迟从哪里来。这就是你 Month 1 的作品集证据。

## 学习节奏建议

- 每周 4 节课，每节 1.5–2 小时（读 + 跑 + lab）。
- `基础` 和 `进阶` 必做；`深入` 第一遍可以跳过，第二遍回来啃。
- 每节课的 lab 必须自己跑到测试通过，不要只看参考解。
- 周末花 1 小时复盘：把这周四节课用一张图串起来。
