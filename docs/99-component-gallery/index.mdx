## 18. QuizCard (章末选择题测验)

可多道题连续测验，判断对错并给出解析。

<QuizCard
  questions={[
    {
      q: '为什么在高并发环境下，系统工程师首选看 p99 延迟指标，而不是看 Average 平均数？',
      options: [
        '因为平均数计算起来太耗 CPU。',
        '因为平均数会掩盖少数长尾极端请求的耗时，而这 1% 的极慢请求会拖慢整个分布式调用链。',
        '因为分位数能直接计算出数据库主从延迟。'
      ],
      answer: 1,
      explain: '在分布式架构中，一个用户的页面渲染往往需要发起几十次微服务子请求。只要 1% 的子请求发生阻塞（p99 飙升），在统计学上这名用户感受到的网页载入就是 100% 变慢。因此，平均数是不具代表性的“欺骗性指标”。'
    },
    {
      q: '一致性哈希 (Consistent Hashing) 最核心解决了什么问题？',
      options: [
        '解决哈希冲突，保证绝对均匀分配。',
        '在服务器节点增减时，只重新映射极少数键值（约 K/N），避免缓存发生大面积雪崩。',
        '将数据库表的写操作变成顺序写入。'
      ],
      answer: 1,
      explain: '传统的普通模余哈希（hash(key) % N）在节点数 N 变动时，几乎 100% 的缓存位置都会发生突变，导致全网缓存瞬间失效并压垮底层数据库。一致性哈希能确保在增减节点时，只有相邻扇区的键会重新路由分发。'
    }
  ]}
/>
